# Vachan S M - Portfolio

Scroll-scrubbed digital marketing portfolio. Plain HTML, CSS and JavaScript, no build step.

## Files (all in one folder)
- `index.html` - page structure, contact card and resume view
- `style.css` - all styles
- `script.js` - scroll scene, panels, contact and resume logic
- `vachan.webp` - transparent-background photo

## Run locally
Open the folder in VS Code, right-click `index.html` and choose Open with Live Server.
Or run `python -m http.server 8000` in this folder and visit http://localhost:8000

## Publish
Upload all 4 files to a GitHub repo (same folder), then deploy with Vercel or GitHub Pages.
